Masuk

Tempel token GitHub Anda. Token hanya disimpan di HP ini, dan cukup dimasukkan satu kali.

Belum punya token? Cara membuatnya (sekali saja, ±2 menit)
  1. Login ke GitHub dengan akun yukata-mika, lalu buka halaman buat token ↗
  2. Token name: isi bebas, misalnya Admin HP
  3. Expiration: pilih yang paling lama
  4. Repository access → Only select repositories → pilih yukata-mika
  5. Permissions → Repository permissions → Contents → Read and write
  6. Tekan Generate token, salin tokennya, lalu tempel di kolom di atas

Jangan bagikan token ke siapa pun. Kalau HP hilang, hapus token di halaman GitHub yang sama.
